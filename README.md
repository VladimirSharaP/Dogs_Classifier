# Dogs_Classifier       

НС для классификации пород собак.       
       
**Задача:**     
Классификация пород собак по фото.    
      
**Что сделано:**    
Проведена настройка модели EfficientNetV2 для задачи классификации пород собак. Проведена аргументация данных для более качественного обучения. Модель обучена классифицировать 10 пород из 120, выбранных случайным образом.      
     
**Использованные технологии:**       
Keras, TensorFlow      
      
**Результаты**     
Модель определяет породу собаки по фото с точностью более 95%.      
      
**Как запустить проект**       
Создайте блокнот в Google Colab     
Скопируйте код из main.ipynb      
Запустите выполнение кода
